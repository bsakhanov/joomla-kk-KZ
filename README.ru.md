Открытый казахский языковой пакет для Joomla 6 и новее: админка, сайт, API веб-служб и установщик. Репозиторий устроен по образцу репозитория русского пакета [JPathRu/localisation](https://github.com/JPathRu/localisation): корень репозитория — корень пакета, один выпуск на версию Joomla, термины собраны в [глоссарии](GLOSSARY.md), ошибки принимаются как issues.

**Страница:** https://bsakhanov.github.io/joomla-kk-KZ/ · **Релиз:** https://github.com/bsakhanov/joomla-kk-KZ/releases/tag/6.1.4.3

## Установка

1. Скачайте `kk-KZ_joomla_lang_full_6.1.4v3.zip` из файлов релиза. Если файла нет, возьмите «Source code (zip)» того же релиза: репозиторий устроен как пакет, и Joomla ставит его так же.
2. В админке: Система → Установка → Расширения → Загрузка файла пакета.
3. Система → Языки → Установленные: сделайте казахский языком сайта и/или админки.

Чтобы поставить саму Joomla на казахском, скопируйте `installation/language/kk-KZ` в `installation/language/` дистрибутива до запуска установщика. Архив `kk-KZ_joomla_lang_root_6.1.4v3.zip` распаковывается прямо в корень Joomla и содержит этот каталог.

## Как ведётся пакет

```bash
python3 tools/kkpack.py fetch 6.1.5                              # английские оригиналы нового выпуска Joomla
python3 tools/kkpack.py status --en .cache/joomla-6.1.5
python3 tools/kkpack.py sync --en .cache/joomla-6.1.5 --write    # новые ключи приходят по-английски, устаревшие уходят
python3 tools/kkpack.py check --en .cache/joomla-6.1.5
python3 tools/kkpack.py build                                    # dist/*.zip и SHA256SUMS
```

Подробно: [docs/MAINTAINING.md](docs/MAINTAINING.md).

## Откуда взят текст

Исходные строки — английские файлы Joomla 6.1.4 (официальный выпуск; официальный репозиторий исходников — [joomla/core-translations](https://github.com/joomla/core-translations)). Казахский текст — прежняя версия этого пакета и перевод с помощью ИИ, сверенные с **официальным казахским переводом** рабочей группы по переводам Joomla (переводчик — Акылкерей Сарваров, [`joomla_v6/translations/package/kk-KZ`](https://github.com/joomla/core-translations/tree/main/joomla_v6/translations/package/kk-KZ); он охватывает 12 146 из 13 471 ключа Joomla 6). Там, где наша формулировка была заведомо неверной, взята официальная строка: 193 строки, список — в [docs/adopt-official.txt](docs/adopt-official.txt).

Официальный перевод не берётся целиком по двум причинам. В нём есть технические дефекты: 31 строка с лишними аргументами printf (на PHP 8 это фатальная ошибка), 7 повреждённых значений, 7 строк с русским текстом, 26 подписей, замещённых длинными предложениями, 61 строк со старым экранированием `_QQ_`, которое Joomla 6 показывает как есть. И в нём есть неверные формулировки в самых видимых местах (Media — «Сурет», Global Check-in — «Жалпы Тіркеу», Overrides — «Өткізуден бас тарту»). Его терминология («мәзір», «санат», «үлгі», «бүркеншік ат») к тому же расходится с решениями этого пакета («меню», «категория», «шаблон», «алиас»). Подробности, примеры и список дефектов — в [docs/OFFICIAL.md](docs/OFFICIAL.md); таблица из 5 419 коротких подписей для вычитки носителем языка — [docs/review/official-diff.tsv](docs/review/official-diff.tsv).

Аккредитованный казахский пакет существует и отдельно: для Joomla 3.9–5.0 ([downloads.joomla.org](https://downloads.joomla.org)); а в дистрибутив Joomla 6 входит частичный казахский перевод установщика. Этот репозиторий — независимый пакет для Joomla 6 и не выдаёт себя за аккредитованный. Идентификатор пакета у обоих `pkg_kk-KZ`, поэтому этот пакет ставится поверх существующего как обновление.

## Терминология

Ориентир — устоявшиеся в языке выражения и международный подход. Международные слова остаются (алиас, плагин, модуль, шаблон, кэш, токен, объект, субъект); решения автора — «сайт», «дерекқор», «қолданба», «пошта». Имена позиций шаблона оставлены латиницей: это идентификаторы. См. [GLOSSARY.md](GLOSSARY.md).

## Что проверено, а что нет

Проверено командой `tools/kkpack.py check`: во всех 537 файлах ключи и их порядок совпадают с оригиналом Joomla 6.1.4; ни в одной строке нет больше аргументов printf и больше переменных вида `{NAME}`, чем в оригинале (иначе страница на PHP 8 упадёт, а в письме останутся сырые переменные); нет неэкранированных кавычек; каждый файл разбирается `parse_ini_file` из PHP 8.3 без ошибок.

Строки также прогнаны через `kk_lint` из [kk-redkollegiya](https://github.com/bsakhanov/kk-redkollegiya) v0.4.5; находки и их разбор — в [docs/QA.md](docs/QA.md).

Проверено и на чистой Joomla 6.1.4 (PHP 8.3, MariaDB 10.11): пакет ставится штатным установщиком Joomla и регистрируется для сайта, админки и API; при казахском языке по умолчанию 79 экранов админки и сайта (списки, формы создания, общая конфигурация, расширения, языки, планировщик, процессы, персональные данные, умный поиск) открывается без ошибок PHP и без «сырых» языковых ключей, а веб-установщик запускается на казахском. Проверку можно повторить: см. [docs/MAINTAINING.md](docs/MAINTAINING.md).

Боковое меню админки дополнительно отрисовано в безголовом Chromium (`tools/sidebar_check.js`): во всех раскрытых разделах ни одна подпись не переносится и ни один значок «+» не уходит на следующую строку.

Не проверено: вычитка носителем языка, визуальный осмотр каждого экрана, API веб-служб с настоящим токеном. Около 270 строк, унаследованных от прежнего пакета, отличаются от оригинала встроенной HTML-разметкой (чаще всего выпали теги выделения); они отслеживаются в issues.
