Joomla 6 Kazakh language pack (kk-KZ)

An open-source Kazakh language pack for Joomla 6 and later: administrator, site, Web Services API and the installer. Version 6.2.0.2 matches Joomla 6.2.0 and has a Kazakh value for every key.

The Kazakh text was translated with AI assistance and has not yet been proofread by a native speaker. Corrections are welcome.

DownloadRepositoryGlossary

Installation

  1. Download kk-KZ_joomla_lang_full_6.2.0v2.zip from the release (or "Source code (zip)").
  2. Administrator: System → Install → Extensions → Upload Package File.
  3. System → Languages → Installed: make Kazakh the default language.

Казахский языковой пакет Joomla 6 (kk-KZ)

Открытый казахский языковой пакет для Joomla 6 и новее: админка, сайт, API веб-служб и установщик. Версия 6.2.0.2 соответствует Joomla 6.2.0, у каждого ключа есть казахское значение.

Казахский текст переведён с помощью ИИ и пока не вычитан носителем языка. Поправки приветствуются.

Установка

  1. Скачайте kk-KZ_joomla_lang_full_6.2.0v2.zip со страницы релиза (или «Source code (zip)»).
  2. В админке: Система → Установка → Расширения → Загрузка файла пакета.
  3. Система → Языки → Установленные: сделайте казахский языком по умолчанию.

Joomla 6 үшін қазақ тілінің пакеті (kk-KZ)

Joomla 6 және одан жаңа нұсқалары үшін ашық қазақ тілі пакеті: басқару панелі, сайт, веб-қызметтер API-і және орнатушы. 6.2.0.2 нұсқасы Joomla 6.2.0-ке сәйкес келеді, әр кілтте қазақша мән бар.

Қазақша мәтін жасанды интеллект көмегімен аударылған және ана тілін меңгерген маманның тексеруінен әлі өтпеген. Түзетулерді қуана қабылдаймыз.

Орнату

  1. Шығарылым бетінен kk-KZ_joomla_lang_full_6.2.0v2.zip жүктеп алыңыз (немесе «Source code (zip)»).
  2. Басқару панелінде: Жүйе → Орнату → Кеңейтімдер → Пакет файлын жүктеу.
  3. Жүйе → Тілдер → Орнатылған: қазақ тілін әдепкі тіл етіңіз.
